# SQLi 手工排查清单

## 适用场景

- 学生在 DVWA SQL 注入 / SQLi-Labs 关卡里「payload 不通 / 无回显 / 报错看不懂」；
- 用户明确说「按清单带我排查 SQL 注入」。

## 排查流程

1. **读取真实上下文**：调用 `fetch_lab_context`，确认关卡页面、表单字段、源码与回显位置；调用 `get_knowledge_card` 获取本关知识卡。
2. **闭合方式**：依次尝试 `'`、`"`、`)`、`')`、`"))` 等，观察报错差异，先判断字符串/数字/括号类型。
3. **注入类型**：
   - 有报错回显 → 报错注入；
   - 有正常回显 → UNION（先 `ORDER BY` 猜列数）；
   - 无回显但页面真假状态不同 → 布尔盲注；
   - 页面完全无差异 → 时间盲注（`SLEEP`）。
4. **过滤绕过**：注释符（`-- ` / `#` / `/**/`）、空格替代（`/**/`、`+`、`%09`）、关键字大小写/双写、`and/or` 替换、宽字节。
5. **验证与记录**：每个假设都要用最小请求验证；成功后总结「闭合方式 + 注入类型 + 关键 payload + 防御要点」。

## 教学原则

- 默认只给方向和下一步验证动作，学生明确要答案时才给完整 payload；
- 一次只推进一个假设，让学生自己贴回显 / 报错结果。
